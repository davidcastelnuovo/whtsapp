# WhatsApp AIOS - תוסף כרום

תוסף כרום שהופך את WhatsApp Web למערכת הפעלה מבוססת AI. התוסף עוטף את WhatsApp Web עם דשבורד חכם שכולל עוזר AI (Claude), אוטומציות, ניתוח שיחות, ומנהל משימות.

## תכונות עיקריות

- **עוזר AI** - סיכום שיחות, הצעות תגובה, ניתוח סנטימנט
- **אוטומציות** - תגובות אוטומטיות, תזמון הודעות, סיווג צ'אטים
- **ניתוחים** - סטטיסטיקות שיחות, אנשי קשר פעילים, ענן מילים
- **משימות** - חילוץ משימות משיחות, לוח קנבאן

## דרישות מקדימות

- **דפדפן**: Chrome או כל דפדפן מבוסס Chromium (Edge, Brave, וכו')
- **חשבון**: WhatsApp Web פעיל ומחובר
- **מפתח API**: Claude API Key מ-[Anthropic](https://console.anthropic.com/)

## התקנה

### 1. הורדת הפרויקט

```bash
git clone https://github.com/davidcastelnuovo/whtsapp.git
```

או הורד כ-ZIP ופרוס את התיקייה.

### 2. טעינת התוסף בכרום

1. פתח את Chrome ונווט ל-`chrome://extensions`
2. הפעל את **Developer Mode** (מתג בפינה הימנית העליונה)
3. לחץ על **Load unpacked**
4. בחר את תיקיית הפרויקט (`whtsapp/`)
5. התוסף יופיע ברשימת התוספים

### 3. הגדרה ראשונית

1. לחץ על אייקון התוסף בסרגל הכלים של Chrome
2. הזן את ה-**Claude API Key** שלך בשדה המתאים
3. לחץ **שמור**

## שימוש

1. פתח את [web.whatsapp.com](https://web.whatsapp.com)
2. התחבר לחשבון WhatsApp שלך (סרוק QR Code אם נדרש)
3. דשבורד AIOS יופיע אוטומטית עם סרגל צד שמאלי

### ניווט בדשבורד

| פאנל | תיאור |
|------|--------|
| **צ'אטים** | תצוגת WhatsApp הרגילה (במרכז) |
| **עוזר AI** | שיחה עם Claude על הצ'אטים שלך |
| **אוטומציות** | הגדרת כללי תגובה אוטומטית ותזמון הודעות |
| **ניתוחים** | סטטיסטיקות ותובנות על השיחות שלך |
| **משימות** | מעקב אחרי משימות שחולצו משיחות |
| **הגדרות** | ניהול API Key, עיצוב, וייצוא נתונים |

### קיצורי מקלדת

- `Ctrl+K` - פתיחת חיפוש מהיר (Command Palette)

## מבנה הפרויקט

```
whtsapp/
├── manifest.json              # הגדרות התוסף (Manifest V3)
├── background/
│   └── service-worker.js      # שירות רקע - API calls, תזמון
├── content/
│   ├── main.js                # נקודת כניסה - אתחול AIOS
│   ├── whatsapp-reader.js     # קריאת נתונים מ-WhatsApp DOM
│   ├── whatsapp-actions.js    # שליחת הודעות, ניווט
│   ├── observer.js            # זיהוי הודעות חדשות בזמן אמת
│   └── ui/                    # רכיבי ממשק הדשבורד
├── styles/
│   └── aios.css               # עיצוב (Dark Theme, RTL)
├── popup/                     # חלון פופאפ של התוסף
├── options/                   # דף הגדרות מלא
├── lib/                       # ספריות עזר (Claude API, Storage)
└── _locales/he/               # תרגום לעברית
```

## פתרון בעיות

- **הדשבורד לא נטען**: ודא שהתוסף מופעל ב-`chrome://extensions` ורענן את WhatsApp Web
- **שגיאות API**: ודא שהמפתח API תקין ושיש לך קרדיט בחשבון Anthropic
- **התוסף לא מופיע**: ודא שבחרת את התיקייה הנכונה (שמכילה את `manifest.json`)
